# Tensura 附属模组制作模板

这是**一个 Gradle 项目**，使用一个模组入口、一个 `MOD_ID` 和一套依赖，项目内部包含六类技能与一套种族进化示例。可直接复制、改名并继续制作附属。

基线：Minecraft **1.21.1** / NeoForge **21.1.219** / Java **21** / Tensura **2.0.0.1** / ManasCore **4.0.0.0**。

## 项目内的示例

| 技能类型 | 示例文件 | 展示的写法 |
| --- | --- | --- |
| 抗性 `RESISTANCE` | `example/skill/resistance/ExampleResistanceSkill.java` | 伤害标签、`onTakenDamage`、通过 `Changeable` 修改伤害 |
| 内在／固有 `INTRINSIC` | `example/skill/intrinsic/ExampleIntrinsicSkill.java` | 被动 `canTick` / `onTick`、与种族固有技能关联 |
| 普通 `COMMON` | `example/skill/common/ExampleCommonSkill.java` | 单模式主动使用、魔素消耗、冷却、熟练度 |
| 额外 `EXTRA` | `example/skill/extra/ExampleExtraSkill.java` | 开关状态、持续生效、周期扣费、资源不足时关闭 |
| 独特 `UNIQUE` | `example/skill/unique/ExampleUniqueSkill.java` | 多模式、模式语言键、不同消耗、各模式冷却 |
| 究极 `ULTIMATE` | `example/skill/ultimate/ExampleUltimateSkill.java` | 范围查询、自身与队友过滤、统一结算 |

上述文件均位于 `src/main/java/com/example/tensuraaddon/` 下。每类技能展示一种实现形式；主动、被动、开关或多模式并不被限定在某个技能等级。

种族部分位于 `example/race/`：

- `ExampleRace.java`：基础种族、斗气与魔素范围、属性修饰、内在技能、下一阶段进化。
- `ExampleEvolvedRace.java`：进化种族、前置种族、保留及新增的固有技能、EP 与技能熟练度条件。

技能和种族分别由 `ExampleSkills`、`ExampleRaces` 注册，并在同一个 `ExampleContent` 中接入模组入口。种族直接引用本项目的内在／抗性技能示例。

## 构建与启用示例

安装 64 位 JDK 21，在本项目目录运行：

```powershell
.\gradlew.bat build
```

产物为 `build/libs/tensura_addon-0.1.0.jar`。第一次使用新电脑时需要联网下载 Gradle 和 NeoForge/Minecraft 工具链；本地开发依赖已放入 `lib/`。默认限制为 2 个 Gradle worker。

`src/main/java/com/example/tensuraaddon/example/ExampleContent.java` 中：

```java
public static final boolean ENABLE_EXAMPLES = false;
```

保持 `false` 时，全部示例源码仍参与编译，但不向游戏注册内容，适合作为空白附属起点。改成 `true` 后重新构建，即同时注册六个技能和两个种族示例。示例提供了具体的方法体与演示数值，正式内容可在对应类内修改。

## 复制为自己的项目

将项目复制到新目录，省略 `.git`、`.gradle`、`build` 和运行目录，然后统一修改以下位置：

- `gradle.properties`：设置自己的 `mod_id`、`mod_name`、`mod_group_id`、`mod_authors` 和 `mod_version`。
- Java 源码：使用 IDE 的包重构功能更新 `com.example.tensuraaddon` 及其全部引用，并修改入口类中的 `MOD_ID`。
- 资源：将 `assets/tensura_addon` 目录改为新的模组 ID，并同步修改中英文语言文件中的命名空间。
- 开发文档：同步更新示例包名、模组 ID 和构建产物名称。

进入新目录后运行 `./gradlew.bat build`。IDE 中打开这一份 `build.gradle` 即可，无需再导入独立的 Race 或 Skill 工程。

## 依赖与开发运行

Gradle **9.2.1** / ModDevGradle **2.0.141**。开发运行库还包括 Architectury **13.0.8**、GeckoLib **4.7.6**、SmartBrainLib **1.16.11**、TerraBlender **4.1.0.8**。

```powershell
.\gradlew.bat runClient
.\gradlew.bat runServer
```

服务端首次运行时由你确认 Minecraft EULA。发布 JAR 不会打入 `lib/` 中的依赖；正式游戏需要安装对应前置。`lib/compile/` 是从同版 ManasCore 聚合包提取的编译模块，不应再单独安装进游戏。依赖来源及校验值见 `lib/README.md` 和 `lib/dependencies.json`。

## 构建验证

2026-09-11，使用 Java 21，以下两种情况均执行 `gradlew.bat build --offline --no-daemon --console=plain` 并构建成功：

- 本项目的默认状态：示例全部编译，注册开关关闭。
- 更改模组 ID、Java 包名及中文显示名，再启用全部示例的项目副本。

已核对 13 个编译类、六类技能与两个种族的资源、改名后的元数据，以及 16 个本地依赖文件的 SHA-256。两份 JAR 的注册入口也与各自开关状态一致。尚未启动游戏客户端或服务端，示例效果仍需在开发环境中实测。
